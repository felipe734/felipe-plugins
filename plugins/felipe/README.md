# Felipe

Paquete con las 4 skills de Felipe OS (felipe-os, felipe-trazabilidad, felipe-recurrentes, felipe-gym), el sistema personal de Felipe Tobar. Se actualiza solo desde este repositorio (rama `claude/` → PR → main); nunca con zip ni skills sueltas.
Independiente de Verse OS: datos y registro en la base FELIPE de Airtable y tarea programada propia (Felipe OS · Recurrentes). Del plugin `verse` solo usa `os-correo` para leer el correo personal.
Mapa y reglas: skills/felipe-os/references/catalogo.md · Prompts de las tareas: skills/felipe-os/references/tareas/ · Validador: scripts/validar_skills.py
